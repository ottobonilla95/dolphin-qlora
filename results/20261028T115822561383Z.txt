[general-01]
PROMPT: Explain what a Python dictionary is to a beginner. Use one short code example.
RESPONSE:
A Python dictionary is a data structure that stores a collection of key-value pairs. It's like a container where you can store multiple items, each with a unique key and a corresponding value. Dictionaries are mutable, meaning you can add, remove, or modify items after they're created.

Here's a simple example of a dictionary:

```
person = {"name":"John", "age":"25", "city":"New York"}
```

In this example, "name", "age", and "city" are keys, and "John", "25", and "New York" are their respective values. You can access a value by its key like this:

```
print(person["name"])  # Output: John
```
